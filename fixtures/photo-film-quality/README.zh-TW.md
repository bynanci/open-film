# 產生的 20 秒照片影片比較

[繁體中文](README.zh-TW.md) · [English](README.md) · [日本語](README.ja.md)

```sh
pnpm exec tsx scripts/photo-film-quality.ts /tmp/openfilm-photo-quality-evidence
```

需要 FFmpeg／FFprobe，以及本機安裝的 CJK 字型。標題繪製器會為設計版本尋找 `Noto Sans CJK TC`，並在每份輸出資訊中記錄實際使用的字型；此腳本不會下載字型。

執行器會產生八張 CC0 校準圖片：含中央、左側及右側主體標記的人像、風景成對圖片、方形細節、片尾圖片，以及兩位主體位於畫面兩側的寬幅圖片。圖片以幾何標記與網格繪製，不含照片或個人素材。另會產生 20 秒合成音樂與 8 秒門控語音形狀音調；後者沒有文字，不能用來判斷旁白清晰度、錄音品質或語言支援。授權請見 [LICENSE](LICENSE)。

`A.mp4` 和 `B.mp4` 均為 960×540、30 fps、20 秒，並使用相同時間軸。A 使用舊版 contain 幾何、直接切換、靜態預設標題與固定音量；B 加入主體保護構圖、兩個雙聯畫、緩慢推近、平移、刻意停留、一次短溶接、三種繁體中文文字角色，以及音訊淡入淡出／自動閃避。主體相距很遠的圖片會測試填滿畫面可能裁掉重要內容時的安全回退。這是校準比較，只改變指定功能，並非自動製片或美學品質保證。

本機輸出包含素材清單與雜湊、可編輯的組合配方與差異、實作來源雜湊、渲染資訊、每部影片 24 個解碼影格的聯絡表、取樣時間、FFprobe 資訊、響度／峰值及 RMS 記錄。部分 manifest 含本機私有 URI；請勿公開，除非先移除路徑。

產生檔案保留在指定本機目錄，不會提交至 repo。兩支影片都必須有視訊與音訊，長度為 20 秒且誤差不超過一格；素材雜湊必須符合輸入。聯絡表可供視覺檢查，但合成素材成功不代表真實素材、聆聽、投影、工作站或 DaVinci Resolve 測試通過。

只產生可重複使用的素材庫：

```sh
node fixtures/photo-film-quality/generate.mjs /tmp/openfilm-quality-media
```
