# 生成された20秒写真フィルム比較

[繁體中文](README.zh-TW.md) · [English](README.md) · [日本語](README.ja.md)

```sh
pnpm exec tsx scripts/photo-film-quality.ts /tmp/openfilm-photo-quality-evidence
```

FFmpeg／FFprobe と、ローカルにインストールされた CJK フォントが必要です。タイトル描画器は設計版で `Noto Sans CJK TC` を解決し、実際に使ったフォントを各レンダーマニフェストに記録します。このスクリプトはフォントをダウンロードしません。

実行すると、人物の中央／左／右位置マーカーを含むポートレート、風景のペア、正方形のディテール、エンディング用画像、画面両端に人物がいる横長画像の計8枚を生成します。幾何学マーカーとグリッドで描画し、写真や個人の素材は含みません。CC0 の音楽音を20秒、ゲート処理した音声風の音を8秒生成します。後者に言葉はなく、ナレーションの明瞭さ、録音品質、言語対応を評価するものではありません。ライセンスは [LICENSE](LICENSE) を参照してください。

`A.mp4` と `B.mp4` は同じタイムラインを使い、どちらも960×540、30 fps、20秒です。A は従来の contain ジオメトリ、カット、固定タイトル、固定音量です。B は保護対象を考慮した構図、2つの二分割画面、緩やかなズームとパン、意図的な静止、短いディゾルブ、繁体字中国語の3種類の文字ロール、音声フェードとダッキングを加えます。離れた位置に被写体がいる画像では、画面を埋めると重要な内容が切れる場合の安全なフォールバックを確認します。これは指定した要素だけを変える校正用比較であり、自動映画制作や美的品質を保証するものではありません。

ローカル出力には素材マニフェストとハッシュ、編集可能な構成データと差分、実装ソースのハッシュ、レンダー情報、各作品24枚のデコード済みフレーム、正確なサンプル時刻、FFprobe 情報、ラウドネス／RMS ログが含まれます。一部のマニフェストにはローカル URI が記録されるため、公開前にパスを削除してください。

生成ファイルは指定したローカルディレクトリに保存され、コミットされません。動画と音声が存在し、長さが20秒から1フレーム以内であること、素材ハッシュが一致することを確認します。合成素材の成功は、実素材の確認、試聴、投影、ワークステーション、DaVinci Resolve の QA に代わるものではありません。

再利用可能な素材のみを生成する場合：

```sh
node fixtures/photo-film-quality/generate.mjs /tmp/openfilm-quality-media
```
