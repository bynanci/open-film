# 生成されたサンプルメディア

[繁體中文](README.zh-TW.md) · [English](README.md) · [日本語](README.ja.md)

リポジトリのルートで `node fixtures/sample-media/generate.mjs /tmp/openfilm-samples` を実行します。FFmpeg が幾何学画像2枚、完全一致する画像コピー、合成音声付き3秒の動きテストパターン、2秒の音を生成します。個人素材やダウンロードした素材は使用しません。生成素材は CC0 1.0 パブリックドメイン、ジェネレーターは Apache-2.0 です。過去の許諾も保持しています。[ライセンス](../../docs/licensing.md)を参照してください。

テストは一時ディレクトリに素材を生成し、FFprobe、FFmpeg、SQLite を実際に使って検証します。生成した元データはプロジェクトディレクトリの外に置き、プロジェクトキャッシュにはサムネイル、動画プロキシ、プレビューのみを保存します。ExifTool があればメタデータを補完し、ない場合は FFprobe とファイルシステム時刻をオフラインの代替として記録します。

_OpenFilm コントリビューターが2026-10-18に更新。現在の第一者素材は Apache-2.0、過去の許諾も引き続き有効です。LICENSE と NOTICE を参照してください。_
