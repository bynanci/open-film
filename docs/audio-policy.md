# 獨立聲音時間（D3B1）

聲音時間屬於既有片段的每次使用。畫面維持已儲存的有理數影格剪點，聲音可提早開始
（J cut）或在畫面結束後延續（L cut）。同一來源的不同片段各自保存聲音選擇。

在片段 Inspector 開啟「聲音時間」，等待原始來源完成驗證後，以整數毫秒輸入起點／終點
偏移，範圍為 −60000 至 +60000。負起點會提前聲音，正終點會延長聲音。「套用」儲存一次
具型別編輯；兩個偏移皆為零時，可明確將連動畫面的片段改用標準聲音時鐘。已獨立的範圍
會保留不足一毫秒的樣本餘數，畫面影格不會移動。

標準時鐘使用第一條音訊串流，解碼為 48000 Hz，保留來源相對於容器的起始位置，並填補
所有內部時間戳空隙。正常 1× 保留樣本相位，不經時間伸縮。舊連動片段仍使用原本的修剪、
延遲與處理器，直到使用者明確套用；改用新時鐘可能改變舊處理器的相位，不會暗中自動遷移。
非 1× 的片段速度仍使用保留音高的處理，需與相同處理時鐘比較。

「重設為畫面」會明確重新連動聲音並顯示結果。Undo／Redo 保留完整物件。首次寫入獨立聲音
會將專案提升至 schema 1.2；移除或 Undo 不降低版本，舊應用程式必須拒絕開啟。明確還原
Named Version 可還原完整的舊專案與舊標頭。

Record 正常播放會使用與 WAV／MP4／分角色音軌相同的 renderer 準備私有完整混音，再排程
有界的兩秒 PCM 區塊。畫面與字幕跟隨聲音；準備或緩衝時保留畫面。取消、暫停、跳轉、
專案變更與 Undo 會淘汰舊播放。非 1× 的 shuttle 明確保持靜音。WebAudio 不支援或準備失敗
時會顯示狀態，不會暗中改用受畫面範圍限制的音訊。

預覽最多支援一小時、每個 PCM 檔 1 GiB、已完成快取 2 GiB，每個專案一次準備工作。
伺服器每次讀取最多四秒，用戶端最多保留八秒。來源不會被覆寫；來源位元組、已儲存內容或
PCM 損毀改變時需重新準備。超出預覽限制時可使用 WAV／MP4 輸出。

角色、增益、淡入淡出、控制點與 ducking 沿用既有控制。後續 coverage 功能可傳入
`keep-primary`、`mix-secondary` 或 `replace-primary`；次要聲音增益限於 0–1，取代只影響
指定主片段的區間。D3B1 不保存 B-roll coverage，也沒有 coverage 編寫控制。

既有限幅器會分別作用於每個分角色音軌與主混音，因此過載音軌相加不會重建已限幅的主混音。
峰值與響度報告量測實際解碼輸出，不會自動正規化已儲存的混音。

獨立聲音在重新連動畫面前不支援分割與替換來源。字幕衝突、來源不足或保護狀態會完整拒絕
儲存。Collect 保留完整原檔，即使同一來源也有連動片段。JSON／OTIO 保留精確中繼資料；
OTIO 需人工重建，FCPXML／EDL 會拒絕無法表示的時間。

實際合成媒體與瀏覽器結果見[驗證紀錄](validation-audio-policy.md)。這些結果不代表硬體音訊
延遲、人工聆聽品質或原生工作站驗證。
