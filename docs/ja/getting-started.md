# スタートガイド

OpenFilm をソースコードから起動し、最初のプロジェクトを作成して MP4 を書き出します。基本的な制作はローカルで動作し、クラウドアカウントや AI プロバイダーは不要です。任意のリモートサービスは、別途設定し、データ送信に同意してから利用します。

最新安定版は **v0.4.0** です。以下のコマンドは現在の `main` 開発版に対応しています。公開済みの版を使う場合は、その版の [release notes](https://github.com/bynanci/open-film/releases)も確認してください。配布可能なネイティブデスクトップインストーラーはまだありません。

## 1. 環境を準備する

Git、**Node.js 24.14.0 以降**、**pnpm 11.11.0**、ターミナルから実行できる **FFmpeg と FFprobe** を用意します。バージョンを確認してください。

```sh
node --version
pnpm --version
ffmpeg -version
ffprobe -version
```

コードと依存パッケージの取得にはネットワーク接続が必要です。通常の編集に Python やモデルは不要です。任意の音声文字起こしを使う場合は、後から[文字起こしの設定](../en/transcription.md)に従って準備してください。

## 2. ローカルワークスペースを起動する

```sh
git clone https://github.com/bynanci/open-film.git
cd open-film
pnpm install --frozen-lockfile
pnpm dev
```

ターミナルを開いたまま、ブラウザーで [http://127.0.0.1:1420](http://127.0.0.1:1420) にアクセスします。OpenFilm のウェルカム画面が表示され、ターミナルにはローカルサービスの `server.ready` メッセージが出力されます。

`pnpm dev` はワークスペース（1420）とローカル API（4310）を起動します。作業が保存されたことを確認してから Ctrl+C で開発プロセスを停止します。これらはローカル開発用サービスです。インターネットへ直接公開しないでください。

ネイティブのフォルダー選択画面を利用する場合は、Tauri のプラットフォーム別必要環境を用意し、実行中の `pnpm dev` を停止してから次を実行します。

```sh
pnpm --filter @openfilm/desktop tauri dev
```

ネイティブ開発ウィンドウと同じローカルサービスが起動します。環境要件とパッケージングの制限は[デスクトップガイド](https://github.com/bynanci/open-film/blob/main/apps/desktop/README.ja.md)を参照してください。CLI を確認するには、リポジトリのルートで `pnpm cli --help` を実行します。

## 3. 最初の映画を制作する

再生できる少量の写真と短い動画を選びます。ウェルカム画面で**フィルムを作成**を選び、名前、ストーリーの種類、映画の言語、目標時間と最大時間を入力します。保存先は**詳細設定**で変更できます。最大時間は目標時間以上にしてください。

| 手順       | 操作                                                                   | 確認する結果                                               |
| ---------- | ---------------------------------------------------------------------- | ---------------------------------------------------------- |
| 素材追加   | ライブラリでファイルかフォルダーを選び、アクティビティの完了を待つ     | サムネイルと取り込み結果が表示される                       |
| 整理       | 素材を確認し、お気に入りを選び、不要なショットを除外する               | 物語に使う場面と利用可能な素材が揃う                       |
| ストーリー | ストーリーを作り、ビートを調整して重要な素材を指定し、カットを作成する | 「編集」に編集可能なカットが表示される                     |
| 編集       | 順序と長さを調整し、「保存済み」を待ってプレビューをレンダリングする   | 現在の映画を確認でき、後の編集で古いプレビューと表示される |
| 書き出し   | 「視聴／共有」で MP4 を書き出す                                        | ローカルの保存先とダウンロードリンクが表示される           |

詳しい操作、ショートカット、復旧方法は[制作の流れ](product-workflow.md)を参照してください。書き出した MP4 を再生し、プロジェクトを開き直して、編集内容と素材を確認します。

## ファイルの保存場所

プロジェクトは作成時に指定したフォルダー、または設定した既定の場所に保存します。ネイティブパスからの取り込みは元の素材を参照し、ブラウザーで選択・ドロップしたファイルはローカルのプロジェクト内へコピーします。いずれも元ファイルを書き換えたり、取り込みのためにクラウドへアップロードしたりしません。

外部参照の元ファイルは保持し、別途バックアップしてください。ドライブやプロジェクトを移動する前に[メディアの移動と再リンク](media-portability.md)と [Collect Media](collect-media.md)を確認します。

## よくある起動時の問題

| 症状                                            | 次の確認                                                                                                                          |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| ワークスペースが開かない                        | 起動したターミナルを確認し、両サービスが動作しているか、別の OpenFilm が 1420／4310 を使用していないか調べる                      |
| FFmpeg／FFprobe が見つからない                  | 上記のバージョン確認コマンドが動くよう PATH を設定し、サービスを再起動する                                                        |
| 素材をプレビューできない                        | [ソース対応](source-support.md)を確認する。元の 360 素材はカメラソフトで平面動画を書き出す必要がある場合がある                    |
| 素材が見つからないと表示される                  | ドライブを接続するか[再リンク](media-portability.md)する。ファイル名だけで置き換えない                                            |
| 文字起こしや対応済み TTS プロバイダーが使えない | 対応機能の[文字起こし設定](../en/transcription.md)または [TTS 設定](../en/provider-generation.md)を確認する。基本編集は続けられる |

解決しない場合は[サポートガイド](https://github.com/bynanci/open-film/blob/main/SUPPORT.ja.md)に従い、バージョン、環境、再現手順、個人情報を除いたエラーメッセージを伝えてください。改善への参加は[貢献ガイド](https://github.com/bynanci/open-film/blob/main/CONTRIBUTING.ja.md)から始められます。
