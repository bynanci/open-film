## まず読むページ

[制作の流れ](/ja/product-workflow)では、プロジェクトの作成、素材の読み込み、ストーリー整理、編集、書き出しを紹介します。[メディアの移動と再リンク](/ja/media-portability)、[カメラソースとプレビューの制限](/ja/source-support)、[プロジェクト形式](/ja/project-format)もご覧ください。

## ドキュメントマップ

### ユーザーワークフローと編集ガイド

[ストーリーテンプレート](/ja/creative-story-templates)、[精密編集](/ja/precision-editing)、[マーカーとスナップ](/ja/markers-and-snapping)、[字幕](/en/composition-captions)、[音声品質](/ja/audio-quality)、[シーケンス波形](/en/sequence-waveforms)、[Visual QA](/en/validation-visual-qa)では、動作、前提条件、制限を説明します。

### 書き出しとメディアの移行

[MP4 圧縮品質](/ja/export-quality)、[Collect Media パッケージ](/ja/collect-media)、[OpenTimelineIO/NLE 互換性](/en/nle-compatibility)、[Resolve ワークステーション QA](/en/resolve-workstation-qa)では、出力形式、メディア移行、外部編集ソフトで確認すべき内容を扱います。

### アーキテクチャ、形式、統合契約

[アーキテクチャ](/en/architecture)、[プロジェクト形式](/ja/project-format)、[統合契約](/en/CONTRACTS)、[編集契約](/en/EDITING_CONTRACTS)、[国際化](/ja/i18n)を参照してください。技術契約と実装資料は主に英語で管理されています。

### ロードマップ、設計判断、研究

[現在のロードマップ](https://github.com/bynanci/open-film/blob/main/ROADMAP.md)、[v1.0.0 の準備状況](/en/roadmap/v1-readiness)、[タスク一覧](https://github.com/bynanci/open-film/blob/main/TASKS.md)、[アーキテクチャ決定記録](/en/adr/001-monorepo)、[研究インデックス](https://github.com/bynanci/open-film/tree/main/research)で、方針、判断、未検証の仮説を確認できます。研究や過去の計画は、承認済みの機能約束ではありません。

### リリースと検証記録

サイドバーでは、リリースノート、アーキテクチャ決定、安全資料、参考ワークフロー、検証記録を分けて表示します。検証ページには、その実行時の commit、OS、ツールのバージョン、コマンド、結果、未完了の手動確認が記録されています。現在の状況は[ロードマップとタスク一覧](https://github.com/bynanci/open-film/blob/main/ROADMAP.md)で確認してください。

## 言語と翻訳への参加

サイトは Git に保存された繁体字中国語、英語、日本語の Markdown を提供します。主要なユーザーガイドは3言語で公開し、アーキテクチャ契約、ロードマップ、リリース、検証記録は現在主に英語で管理しています。閲覧時の自動翻訳は行いません。翻訳時はコマンド、パス、識別子、測定値、証拠リンクを変更しないでください。[ドキュメントの言語方針](/ja/i18n)を参照してください。

ドキュメントの修正は[GitHub](https://github.com/bynanci/open-film)から歓迎します。貢献手順と報告方法は[コントリビューションガイド](https://github.com/bynanci/open-film/blob/main/CONTRIBUTING.md)をご覧ください。
