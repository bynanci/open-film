## クイックスタート

[制作の流れ](/ja/product-workflow)では、プロジェクトの作成、素材の読み込み、ストーリー整理、編集、書き出しまでを紹介します。素材の移動は[メディアの移動と再リンク](/ja/media-portability)、カメラや形式の制限は[カメラソースとプレビューの制限](/ja/source-support)をご覧ください。

## 制作の流れ

プロジェクト作成 → 素材を読み込む → ストーリーを整理 → 編集・プレビュー → 書き出し

## 言語とドキュメント

サイトは Git に保存された繁体字中国語、英語、日本語の Markdown を使い、閲覧中の即時翻訳は行いません。主要な5つのガイドに加え、クリエイティブストーリーテンプレート、精密編集、ソースマーカーとスナップ、MP4 圧縮品質、音声品質のページには3言語の保存版があります。その他の技術資料は今後翻訳します。
