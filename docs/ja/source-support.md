# カメラソースとプレビューの制限

デバイスアダプターは @openfilm/source-pixel と @openfilm/source-insta360 にあります。ポータブル Core にデバイス固有の分岐はありません。アプリはローカル取り込み時にアダプターのメタデータ補足を適用します。元の EXIF／FFprobe 記録は、解釈したフィールドとともに保持されます。

| ソース                                         | 実装済みの動作                                                                          | 検証した証拠                                                                      | 残っている手動確認                                             |
| ---------------------------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| Pixel JPG／MP4                                 | Google／Pixel メタデータを認識し、日付／オフセット、向き、GPS、デバイス、技術情報を保持 | ExifTool でタグ付けした生成 JPG／MP4、取り込みとプレビューのテスト                | 代表的なカメラ原本と向きの表示                                 |
| DNG                                            | メタデータを保持し、上限付きデコードに成功した場合のみプレビュー                        | 生成した TIFF／DNG タグとメタデータのみの DNG フィクスチャ                        | 実機 Pixel の CFA／デモザイクとカメラ色                        |
| HEVC 10-bit HLG／PQ                            | 検出して元の色フィールドを保持し、プレビューを SDR にトーンマップ                       | 生成 HEVC、実際の FFprobe、サムネイル、プロキシ、レンダラー。元のハッシュは不変   | 実際の HDR 表示とデバイス固有メタデータ                        |
| Pixel Motion Photo                             | 埋め込みオフセット、サイドカー、メタデータ参照を根拠付きで検出                          | 模擬メタデータ、埋め込みデータ、名前付きサイドカー                                | 実機カメラの種類と抽出。実験段階                               |
| Insta360 のフラット書き出し JPG／MP4、レベル 1 | 通常再生できるメディアとして扱い、デバイス情報とソース関連付けを保持                    | タグ付き生成 JPEG／H.264 をデコードし、サムネイル、プロキシを作成してレンダリング | 代表的な実機書き出し、特に特殊なコーデック                     |
| .insv／.insp、レベル 2                         | 認識し、可能な範囲でメタデータを取得し、元ソースに関連付け                              | 模擬ソースと、明示的または慣例に基づく同階層ファイルとの関係                      | 実際のカメラ原本とハードウェアメタデータ                       |
| RAW／球面処理、レベル 3                        | 機能の状態を記録。再フレーミングした書き出しが必要                                      | 球面メタデータを明示し、RAW のフラットプレビューをブロック                        | スティッチング、ジャイロ、再フレーミング、キーフレームは未対応 |

レベル 1 は通常の本番メディア処理経路を使います。すべてのカメラコーデックや RAW 形式が検証済みという意味ではありません。ファイル名だけで Pixel 由来とは判断しません。不確かなファイルは一般的なカメラとして扱います。Insta360 の関連付けには判定根拠を記録しますが、2 つのファイルが同じ内容のソースだとは保証しません。球面投影が明示されていれば、MP4 や JPG でも 360 メディアとして扱います。縦横比 2:1 だけでは球面投影と判断しません。

HDR 検出ではビット深度とダイナミックレンジを区別します。10-bit や BT.2020 だけでは HDR を意味しません。HLG／PQ の伝達関数と HDR サイドデータは openfilm.color と元のプローブ記録に保存します。既知の伝達関数／原色／マトリクスがあり、FFmpeg に zscale と tonemap がある場合に限り、安全な SDR プレビューを作成します。色メタデータが不明、またはフィルターがない場合は、対処方法を示す「プレビュー非対応」メッセージを表示します。OpenFilm はカタログ情報を保持し、誤ったプレビューを黙って生成しません。これはプレビュー変換であり、完全なカラー管理やグレーディング機能ではありません。

RAW の 360 ソースには「360 ソース／再フレーミングした書き出しが必要」と表示されます。Insta360 Studio でスティッチして再フレーミングしたフラット JPG／MP4 を書き出し、そのファイルを取り込んでください。デコードできない DNG も、プレビューには書き出した JPEG が必要です。非対応ソースも閲覧できますが、自動ストーリー構成には含まれません。明示的に必須にした非対応素材は、構成やレンダリングの前に変換してください。

これらのアダプター導入前に取り込んだプロジェクトは、ソースフォルダーを再取り込みしてデバイス／色メタデータを更新し、バージョン付きプレビューキャッシュを再構築してください。ID、評価、ロック、タイムライン参照は維持されます。プレビュー用プロキシはプロジェクト内にキャッシュされ、欠落時には再構築の手順を表示します。この処理で元ファイルを書き換えることはありません。

コミット済みのすべてのフィクスチャ定義は生成データまたはパブリックドメインです。出所と再現方法は [fixtures/proposal-film](https://github.com/bynanci/open-film/tree/main/fixtures/proposal-film) をご覧ください。個人の実カメラメディアは含まれていません。

## 一般メディアのブラウザープレビュー

JPEG、PNG、WebP、GIF、BMP は対応する画像 MIME タイプで配信します。TIFF、AVIF、正常にデコードできた HEIC／DNG、HDR 画像にはキャッシュ済み JPEG プレビューを使います。非対応または欠落した派生ファイルがある場合は、デコードできないソースデータをプレーヤーに送らず、再構築または変換の具体的な手順を表示します。

取り込んだ音声には、AAC、M4A、FLAC、Ogg、Opus を含め、プロジェクト相対パスの MP3 プレビューキャッシュを作成します。埋め込みアルバムアートはメタデータのままで、音声ファイルを動画クリップにはしません。レンダリングとタイムライン書き出しは元の音声参照を保持します。プレビュー変換でソースを書き換えることはありません。旧形式の音声のみの素材を再取り込みすると、不足するプレビューを作ります。プロキシを無効にすると元の音声を直接使うため、ブラウザーのネイティブコーデック対応に依存します。

tests/integration/preview-formats.test.ts は、GIF、BMP、TIFF、AVIF、音声ファイルを生成します。カバーアートを埋め込んだ MP3／FLAC も含まれます。HTTP MIME、配信バイト、音声コーデック、バイト範囲、キャッシュ欠落からの復旧、プロジェクト移動、ソースハッシュ不変を検証します。HEIC の範囲はカタログ／キャッシュ経路のフィクスチャであり、実際の HEIC デコードやカメラ互換性を証明するものではありません。インストール済み FFmpeg ビルドで代表的な HEIC を取り込んで確認する必要があります。
