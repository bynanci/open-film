# クリエイティブストーリーテンプレート

クリエイティブストーリーテンプレートは、既存の version-1 `GraphicScene` プリミティブを組み合わせて編集可能なシーンを作ります。別のタイムライン、レンダラー、アセットストアを作成したり、プロジェクト schema を移行したりしません。シーンの配置と表示時間は、保存済みの Composition と通常の `GraphicScene` ノードに保持されます。

## ギャラリーとインスペクター

「編集」インスペクターには、ローカルで使えるテンプレートが3種類あります。

- **会話カード**：1〜4組の話者／メッセージを作成します。キーボード操作に対応したコントロールで並べ替え、シーン内の時計に合わせてタイミングを設定できます。テキストはそのまま扱い、改行に対応します。保存前に各カード枠に収まるよう慎重に調整し、最小サイズでも入らない内容は書き出し時の失敗を避けるため拒否します。カードは中央配置でセーフフレームに収まる余白を持ちます。「グラフィック」ではノードごとにフォント、改行、位置を編集できます。テンプレートのコントロールからレイヤーのアニメーション時間とイージングを設定します。
- **ルートストーリー**：緯度／経度の地点を直接入力するか、ユーザーが選択した GPX ファイルのデータを読み込みます。地点は点線のルートとして順に表示され、名前付きウェイポイントは元の座標と関連付けられたままです。読み込んだ元ファイル名と SHA-256 を保持します。時刻、高度、速度、距離、レース結果、イベントに関する主張を推測または読み込みません。
- **写真の関係性**：焦点の表示、2枚の写真の比較、オープニング／クロージングの構成に対応します。各画像ノードはローカルカタログのアセットを参照します。焦点と任意の保護領域は元写真に対して正規化します。画像はフレーム全体に収めるため、初版では出力から保護領域が切り取られません。

保存したテンプレートはインスペクターで再度開き、テキスト、シーンのタイミング、アニメーション、関係性、写真ソース、焦点、保護領域を変更できます。フォント、改行、レイヤーごとの位置調整には既存の「グラフィック」インスペクターを使用します。テンプレートの変更は既存の `graphic.scene.upsert` コマンドを呼び出し、任意でテンプレート記録を付加します。Composition のリビジョン確認、ロック状態、Undo／Redo、自動保存、再試行、再オープンは既存のエディターアプリケーションを通して処理されます。

## ソースの帰属

会話のメタデータは安定したメッセージ ID を使って、既存の話者、テキスト、任意のソースラベルノードを関連付けます。`quoted` のテキストは保存済みの原文全体と一致する必要があります。`excerpt` は保存した UTF-16 範囲と一致し、ローカライズされた抜粋ラベルを表示します。`adapted` は原文と引用を残し、表現が変更されたことを示します。インスペクターは3種類のラベルと、書記素単位の開始／終了位置を表示します。シリアライズされた UTF-16 範囲が emoji などのサロゲートペアを分割することはありません。引用または抜粋を編集すると、保存前に表示ラベルが `adapted` に変わります。ソースのメタデータを削除する場合はインスペクターで明示的に操作します。この機能がソース文を AI プロバイダーに送信することはなく、ソース文の長さにも上限があります。

ルートのメタデータは、保存された地図上の地点を形状ノードに結び付けます。GPX インポーターは読み取り専用で、最大4 MiB の UTF-8 XML を受け付けます。DTD、エンティティ、コメント、処理命令、不正な XML、複数のトラックセグメント／ルートを含むファイルは拒否します。表示地点は最大32件、名前付きウェイポイントは最大8件です。ルート地点が32件を超える場合、決定的な等間隔サンプリングで始点と終点を保持します。保存するのは読み込んだファイルの正確なハッシュと表示用の形状データのみです。元ファイルのパス、タイムスタンプ、高度、速度、アクティビティ概要は保存しません。

写真のメタデータには、画像ノードの識別情報、関係性の役割、カタログのアセット ID、任意のソースハッシュ、焦点／レイアウトデータを関連付けます。比較には異なるアセットが2つ必要です。レンダラーは既存のローカル画像データを読み、同一性を検証します。テンプレートが元メディアを上書きすることはありません。

## 制限と信頼境界

すべてのメタデータはバージョンフィールド、件数制限付き配列、リテラルテキストを含む厳密な JSON です。型付き編集を確定する前に、保存された正確なシーンとノードの種類に照らして検証します。不明なフィールド、対応ノードのない ID、存在しないアセット、不正なハッシュ、安全でないファイル名、無効な座標は拒否します。GPX はデータとしてのみ解析します。ネットワークリクエスト、プロジェクト HTML、スクリプト、リモート URL、XML エンティティ展開、第三者テンプレートコードは実行しません。

出力レンダラーは引き続き対応する `GraphicScene` だけを処理します。メタデータは編集上の出所と置換時の文脈を記録するもので、レンダープリミティブを追加したり既存のリソース制限を回避したりできません。
