# Product pain points

Prioritize a user's blocked decision or recovery step before adding another feature.
Status describes evidence: **Planned**, **In Progress**, **Automated Verified**,
**Hardware Verified**, or **Released**. Merging source does not certify an installer,
model's recognition quality, GPU, camera, or downstream NLE.

The current implementation slice is ownership-aware media-analysis recovery,
stacked on the verified, still-open PR #8 cancellation change. It retains the
existing Library → Story → Edit → Export navigation, SDK transcription port,
SQLite project storage, word alignment, and composition engine. It does not start
semantic search, face analysis, reframing, derived films, captions, or cloud work.

Progress, result publication and interrupted-work recovery share the same durable
owner boundary; a UI cancellation action also requires this server to own the
actual cancellation signal. Other creative milestones remain deferred.
