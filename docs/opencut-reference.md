Current OpenCut's `README.md` announces an Editor API, plugin-first architecture,
Rust cross-platform core, MCP, headless mode and scripting. These are declared
rewrite directions. At the pinned commit `apps/web/src/routes/editor.tsx` renders
“Coming soon”, `apps/desktop/src/panels/{preview,timeline}.rs` are shell panels,
and `crates/media/setup/{setup.ts,ffmpeg.json}` supplies dependency preparation.
The inspected current source does not establish a working runtime for those
announced editor capabilities. The shell and build recipe must not be represented
as a completed editor or plugin platform.

## What the historical implementation actually provides

All paths in this table are in classic at the pinned commit. “Tests present”
means source was read, not that the suite was executed in this task. Neither
OpenCut repository was installed, built or run.

| Area and evidence                                                                                                                                                                     | Observed implementation / test evidence                                                                                                                                                                                                                                                                                                 | Principle for OpenFilm and boundary                                                                                                                                                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Actions: `apps/web/src/actions/{definitions,registry,use-editor-actions}.ts`; commands: `apps/web/src/{commands/base-command.ts,commands/batch-command.ts,core/managers/commands.ts}` | UI/keyboard action binding invokes editor managers and commands. Command history stores selection snapshots and explicitly applies ripple when enabled; batches undo in reverse order. Keybinding persistence tests exist under `actions/keybindings/__tests__`. No claim that this makes all operations headless or transaction-safe.  | **Adapt** separation of UI intent from shared validated operations. OpenFilm already has `TimelineCommand` and application revision/request receipts; reuse them. A read-only subtitle export does not enter timeline history or ripple editing. No new general Command Bus. |
| Timeline state: `apps/web/src/core/index.ts`, `core/managers/{timeline-manager,scenes-manager,save-manager}.ts`                                                                       | `EditorCore` owns managers; scenes own tracks. This is actual historical source, not evidence for the new rewrite API.                                                                                                                                                                                                                  | **Adapt** explicit ownership; preserve OpenFilm project/application/catalog boundaries and source revisions. Do not move project state into a Vue or React store.                                                                                                            |

OpenFilm's seconds, positive speed validation, trim ranges and transition rules remain authoritative; do not copy rate clamping that would disguise unsupported timing.                          |
