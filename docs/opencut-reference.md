Current OpenCut's `README.md` announces an Editor API, plugin-first architecture,
Rust cross-platform core, MCP, headless mode and scripting. These are declared
rewrite directions. At the pinned commit `apps/web/src/routes/editor.tsx` renders
“Coming soon”, `apps/desktop/src/panels/{preview,timeline}.rs` are shell panels,
and `crates/media/setup/{setup.ts,ffmpeg.json}` supplies dependency preparation.
The inspected current source does not establish a working runtime for those
announced editor capabilities. The shell and build recipe must not be represented
as a completed editor or plugin platform.

The selected flow is therefore **corrected transcript → current composition →
reviewable cues/warnings → SRT/WebVTT with provenance**, not a caption-track,
burn-in, re-transcription, styling, keyframe, plugin or compositor project.

## Licensing and verification limits

Both inspected repository-root `LICENSE` files grant MIT terms (current copyright
2026 OpenCut; classic copyright 2025–2026 OpenCut). This is not a blanket license
claim for assets, dependency bundles or externally downloaded models. For example,
current `crates/media/setup/ffmpeg.json` explicitly labels its pinned FFmpeg build
`LGPL-2.1-or-later`. None of those files or bundled materials are imported here.
The work adapts concepts through original implementation, retaining OpenFilm's
Apache-2.0 license. Any future substantial code copy must carry the exact source,
commit, affected paths and required copyright/permission notice.

Source review does not verify OpenCut execution, real ASR quality, GPU speed,
caption playback in Resolve, Windows installers or camera/4K quality. OpenFilm's
existing workstation manual gates remain in effect; format parsing only verifies
that specific exported file format and cannot close those gates.
