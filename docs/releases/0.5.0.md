# OpenFilm 0.5.0 candidate

**Unpublished source-only candidate.** This page records the proposed first
staged release scope. It does not announce a published release or certify a
native installer.

The scope is anchored at PR #75 merge `d5a286ed9250872e8eb9b1c3e40adb926f913d34`.
The candidate version surfaces are aligned to `0.5.0`; the release tag remains
blocked until the exact candidate passes its full gates and the release owner
reviews the evidence.

## Included workflow

- Story Graph, StoryPlan and the guided Pipeline support reviewable story-to-cut
  planning without creating another timeline.
- Creative Variants preserve the existing Composition and allow explicit A/B
  review.
- Quiet Studio and the first Professional Cut Desk workflow organize controls
  around the current editing task.
- Focal-point photo presentation, eased movement, ambient fill and bilingual
  title finishing improve visual authoring while retaining the shared renderer.
- Existing project schema, source media, Undo/Redo, autosave and reopen behavior
  remain the compatibility baseline.

## Distribution and limits

This candidate is intended as a source archive. It does not include signed
Windows/macOS installers or an automatic update feed. Clean-machine installation,
update recovery, uninstall preservation, real hardware/media quality, Resolve
round-trip and sustained 4K/GPU performance remain separate manual gates.

The GLib `RUSTSEC-2024-0429` unsoundness finding is not considered closed by this
candidate preparation. The security remediation must receive independent review
and be included in the exact candidate before release approval.
