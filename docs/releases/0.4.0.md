# OpenFilm 0.4.0

OpenFilm 0.4.0 brings the reviewed creative-scene workflows together on one
Composition and renderer. Editing stays local-first, story-first and
non-destructive, with the existing project schema 1.0.0, Undo/Redo, autosave and
reopen behavior.

## Included workflows

- Selective local PhotoDepth with protected subjects, source/mask receipts,
  bounded arbitrary-seek parallax, fallback and typed Visual QA diagnostics.
  Foreground masks now preserve the original photo's transparency.
- Professional still PNG, WAV and aligned audio stems, landscape/portrait/square
  profiles and review-bound crop confirmation. Mixed mono/stereo stems share one
  channel layout; audio-only output does not require unrelated visual originals.
- Reviewable NLE handoff with native/metadata/baked/unsupported explanations,
  explicit opaque precomps/full mix, portable sources and verification receipts.
- Collect Media directory/ZIP packages with complete referenced-source and font
  checks, explicit rights, safe paths, stable provenance and actual reopen/render
  verification. Known credential paths reject before byte reads; supported media
  is checked by decoding its required stream, including Story-only references.
- Verified native runtime and installer-candidate tooling, owned-service lifecycle,
  signature-bound manifest bytes, permission-preserving archives and portable
  build invocation. Runtime retry retains authored drafts with project/source
  fences and explicit export/discard; pending recovery keeps close guards active.
- Motion candidate comparison with explicit Accept/Replace/Restore, local camera
  fixtures and explicitly imported local videos. Interrupted previews no longer
  retain expired private bytes or permanently occupy preview capacity. Catalog
  adoption retries preserve accepted source identity and earlier Undo history.

## Recovery and compatibility fixes

Named Versions can explicitly delete selected snapshots to free bounded storage.
Deletion requires confirmation and a current saved revision; recovery journals
protect checkpoints. Restore rechecks target sources after checkpoint creation
and refuses to proceed if its checkpoint disappeared. Version comparison now
preserves legal composite IDs and ordering; sorted-source validation is linear.
Application, workspace and native-shell versions are aligned with this release;
snapshot software-version receipts read current application metadata.

Original media and existing schema versions remain unchanged. Older snapshots
retain their original metadata. Source/media locks, required selection and
explicit provider consent remain authoritative.

## Distribution and remaining validation

This is a source release. Signed Windows/macOS installers and an automatic-update
feed are not distributed. Native bundling remains disabled by default; the
installer workflow creates manual candidates only. Linux CI and synthetic media
verification do not certify clean-machine Windows/macOS installation, physical
HDR/display appearance, sustained 4K/GPU performance, hardware listening or actual
Resolve/NLE import fidelity.

Remote image-to-video is disabled. The deterministic local camera fixture is not
AI generation. Paid-provider terms, cost, retention and subject-detail quality
need separate review before any future remote adapter is enabled. Private photos
are never silently uploaded.

Exact candidate/merge identities, test results and synthetic FFmpeg evidence are
recorded in [release validation](../validation-stable-release.md). Apache-2.0 and
NOTICE are retained.
