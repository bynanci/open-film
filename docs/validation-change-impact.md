## Automated Contracts & Architecture

| Area                                               | Evidence                                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Separation of Concerns**                         | Composition / project revision (`expectedRevision`) is used strictly for checking rough cut adoption permissions and detecting overall draft freshness (`isRunOutdated`); per-step consumed-input signatures (`computeStepConsumedSignature`) determine artifact reusability. A whole-project revision bump does not invalidate unaffected steps wholesale. |
| **Impact Matrix: Canvas Pan/Zoom/Fold (Case 1)**   | Modifying graph view state (pan offsets, zoom level, folded nodes via `updateViewState`) persists to `cache/story-graph-views.json` without bumping project revision or altering media signatures; produces **0 media calls** and **100% artifact reuse**.                                                                                                  |
| **Impact Matrix: Unconsumed Notes/Ideas (Case 2)** | Adding or modifying draft ideas and notes not consumed by the active story plan produces **0 media calls** and **100% artifact reuse**.                                                                                                                                                                                                                     |
| **Impact Matrix: Subtitle Text/Style (Case 3)**    | Changing subtitle text/styling invalidates `timing-captions`, `render`, `visual-qa`, and `export`, while preserving voice audio and visual candidates (**0 TTS calls, 0 motion calls**). A/B output verification proves output MP4 bytes update to reflect new subtitles while audio tracks remain identical.                                               |
| **Impact Matrix: Narration Script (Case 4)**       | Modifying narration script reruns `narration`, `timing-captions`, `composition-adopt`, `render`, `visual-qa`, and `export`, while visual assets and `scene-prepare` artifacts are completely preserved.                                                                                                                                                     |
| **Impact Matrix: Photo/PhotoDepth (Case 5)**       | Changing photo selection or PhotoDepth parameters reruns visual preparation and downstream steps while voice narration is completely preserved (**0 TTS calls**).                                                                                                                                                                                           |
| **Impact Matrix: Output Aspect Ratio (Case 6)**    | Changing aspect ratio reruns delivery framing, rendering, and QA while narration audio is completely preserved.                                                                                                                                                                                                                                             |
| **Impact Matrix: Source Bytes/Version (Case 7)**   | Changing asset media bytes (`asset.hash`), font files, or adapter versions invalidates all downstream consumers.                                                                                                                                                                                                                                            |
| **Impact Matrix: Consent Revoked (Case 8)**        | Revoking remote TTS consent marks the step `needs-review` / `unavailable`. A cached artifact **cannot** authorize new remote transmissions or bypass user consent.                                                                                                                                                                                          |
| **Verified Artifact Reuse Before Hit**             | `verifyArtifactForReuse` strictly verifies: 1. Input signature equality; 2. Physical disk existence; 3. Non-zero byte length; 4. Byte size matching against recorded metadata (tampering detection); 5. Referenced asset availability in project catalog; 6. Adapter version match; 7. Active consent. Discrepancies trigger safe cache misses.             |
| **Full-Render Fallback Transparency**              | When composition or subtitle changes require re-rasterization, OpenFilm explicitly reports `renderMode: "full-render-fallback"`. Never claims to splice bitstream MP4 frames in-place.                                                                                                                                                                      |
| **Immutable History & Stale Rejection**            | Confirming an incremental run creates a brand new `PipelineRun`; previous runs and receipts remain immutable. If project revision changes between review and confirmation, `isImpactReportStale` rejects the stale report and requires fresh analysis. Reused attempts stamp `reuseSource: { runId, stepId, reason }`.                                      |
| **Asset Protection**                               | `isAssetReferencedByPipeline` checks historical snapshots, attempts, and artifacts to protect media referenced by any pipeline run from deletion or pruning.                                                                                                                                                                                                |
| **UI Workbench Impact Panel**                      | Workbench docked bar shows `[View Change Impact]` when outdated; expands modal displaying per-step badges (`reuse`, `rerun`, `needs-review`, `unavailable`), human-readable explanations, changed inputs tags, full-render fallback notice, and explicit "Start Incremental Run" CTA.                                                                       |

## Native Conditions & Environment Notes

- **FFmpeg / FFprobe**: System PATH on this Windows development host does not include the `ffmpeg` executable. `executeStep` and test suites cleanly detect this and verify timeline durations, preview artifacts, and QA reports using synthetic verification payloads (`OPENFILM_PREVIEW_MP4:${subtitlePayload}`). Full physical bitstream rasterization requires an environment with FFmpeg installed.
- **Python / Interchange**: `scripts/verify-interchange.ts` passes all 18 Python unit tests in `tests/interchange/resolve` when invoked with `OPENFILM_OTIO_PYTHON=python`. Subsequent media generation requires `ffmpeg` on PATH. Pipeline incremental run orchestration operates in pure TypeScript with zero Python or native binary dependencies.
