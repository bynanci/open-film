# 在 OpenFilm 製作影片

這份指南帶你完成「加入素材 → 整理 → 故事 → 剪輯 → 輸出」五個步驟。完成後會得到可重新開啟的 OpenFilm 專案和可播放的 MP4；也可選擇輸出到其他剪輯器繼續製作。

基本流程在本機執行，不需要雲端帳號或 AI。選用的遠端供應商必須先設定，並在傳送資料前取得你的同意。首次使用請先完成[環境設定與啟動](getting-started.md)。本頁對應目前 `main`；已發布版本的功能請同時查閱 [release notes](https://github.com/bynanci/open-film/releases)。

## 開始前：建立專案

歡迎畫面提供「建立影片」、「開啟專案」和最近開啟的影片。最近項目會標示儲存位置目前是否可用；即使位置遺失，開啟項目也不會刪除它。開啟影片前即可使用語言與設定。

建立影片時，請輸入名稱、故事類型、影片語言，以及目標／最長片長。「提案影片」範本預設目標為 4 分 30 秒、上限為 5 分鐘；這些是範本預設值，不是 Core 的硬性限制。儲存位置位於「進階」選項；本機服務會在設定的預設位置建立唯一的專案資料夾。你也可以在設定中變更之後新影片的預設位置。

介面語言與影片語言互不依賴。變更介面語言會立即更新按鈕和說明；變更影片語言會更新已知的範本預設文字，自訂標題與意圖則維持原樣。

## 1. 加入素材

「加入媒體」可選擇資料夾或個別檔案。原生桌面應用程式使用本機選擇器和檔案路徑；透過瀏覽器選取或拖放的檔案會由本機服務複製到專案內，不會上傳到雲端。原始檔案始終保持不變。精簡的「活動」區會顯示進度、完成狀態和需要處理的檔案，也可取消正在執行的匯入或算繪工作。

**預期結果：** 素材庫出現縮圖和匯入結果。先處理「活動」中失敗或不支援的素材，再繼續製作。來源格式的條件請見[相機與來源支援](source-support.md)。

## 2. 整理素材

素材庫提供「全部」、「時刻」、「相似」、「最愛」、「已排除」和「遺失」檢視。選取縮圖即可檢視素材；可將素材加入最愛、排除不需要的片段，或鎖定重要回憶。你可以把相關時刻和重複鏡頭整理成群組。裝置、拍攝時間依據、GPS、編碼、色彩和完整來源路徑會顯示在檢視器或技術資訊中，不會塞進縮圖聯絡表。

「加入媒體、整理、故事、剪輯、輸出」進度列會顯示建議的下一步和需要留意的狀態。它不是鎖住操作順序的精靈：你仍可自由切換頁面；若後續步驟需要先建立故事或剪輯，空白狀態會提供指引。

**預期結果：** 你已辨認想保留的時刻、排除不需要的素材，並知道有哪些來源仍需處理。

## 3. 建立故事

依照影片所選的範本和片長預設建立故事。故事板會列出各段落的標題、時間安排和已選素材數量。選取段落即可調整標題、意圖和目標時間；已選素材會與建議素材分開顯示。將素材指定到某段落後，該素材便會成為必要素材。

更新建議會依照目前偏好重新排列該段落既有候選素材；不會取代已選素材，也不會更動其他段落。建立剪輯後，故事會進入「剪輯」工作區。

**預期結果：** 故事段落、重要素材和片長意圖已轉成可編輯的剪輯。需要進一步設計畫面時，可閱讀[故事模板](creative-story-templates.md)與[場景腳本規劃](en/scene-script-planning.md)。

## 4. 剪輯與預覽

片段會依故事段落分組。選取照片可調整停留時間和構圖；選取影片可修剪片段、調整速度／音量和構圖。照片與影片片段可使用直接切換、交叉淡化，以及淡入淡出至黑色／白色。音訊提供支援的修剪與音量控制。可拖曳片段，或使用「提前／延後」重新排序。鎖定可避免重要片段被取代、刪除或重新產生。

片長資訊會同時顯示實際、目標和最長片長。「符合目標」會提出可說明的調整，並以目前影片為基準計算。預覽會檢視提議的變更，但不會儲存；「套用」會提交變更；「略過」會在更新計畫時排除此片段。「全部套用」顯示的是依序執行的計畫總長，不是各個獨立方案長度的加總。若受保護素材使影片無法達到目標，介面會說明原因，不會默默刪除素材。

編輯會在短暫停頓後自動儲存。「已儲存」、「儲存中」和「儲存失敗」會反映實際狀態。編輯工作階段中可使用復原與重做。若發生衝突，草稿會保留下來，並提供檢視／重新套用或明確捨棄的選項；切換語言不會重設編輯器。預覽會算繪目前影片；之後若再編輯，預覽會標示為過期，直到重新算繪。

一般「故事」檢視中，空白鍵播放／暫停，左右方向鍵選取相鄰片段，Delete 刪除符合條件的已選片段。Ctrl/Cmd+Z 復原，Ctrl/Cmd+Shift+Z 重做。

「專家模式」提供「分頁單螢幕」與「雙螢幕並排」版面。先選擇「來源」（Source）或「成片」（Record）監看螢幕；空白鍵控制目前使用中螢幕的播放，左右方向鍵則逐格移動。非逐字稿檢視中，按 `?` 可開啟快捷鍵參考清單。輸入欄位和對話框保留一般打字與鍵盤操作行為。「提前／延後」也提供可使用鍵盤完成的重新排序方式。

**預期結果：** 修改已儲存，且你已看過最新預覽。再依需求加入[字幕](en/composition-captions.md)、調整[音訊品質](audio-quality.md)或使用[精準剪輯](precision-editing.md)。需要跨工作階段保留一個可比較的版本時，使用[命名版本](en/named-versions.md)。

## 5. 輸出並檢查

輸出會先詢問用途：「觀看／分享」會建立 MP4；「繼續剪輯」會提供現有的 NLE 輸出目的地。「進階」可使用現有交換格式。MP4 輸出會算繪已儲存的影片，並提供本機輸出位置和瀏覽器下載；不會把過期預覽檔當成完成影片。

輸出到其他剪輯器時，請保留輸出報告並一併準備素材。一般交換格式可保留支援的剪輯結構，進階效果可能只保留為中繼資料，需在目的地重新製作。若選擇算繪後的交接方式，也要確認可編輯範圍。詳見 [NLE 交接](en/nle-handoff.md)與[相容性矩陣](en/nle-compatibility.md)；實際 Resolve 匯入仍需工作站驗證。

**預期結果：** 取得輸出檔案、位置與相容性報告。實際播放 MP4，檢查開頭與結尾、字幕、聲音及代表性轉場；再關閉並重新開啟專案，確認修改與素材仍可讀取。需要調整壓縮時，請看[輸出品質](export-quality.md)。

## 磁碟機離線時

媒體離線時，素材縮圖、故事位置和編輯仍會保留。可對單一素材使用「尋找檔案」，或對已搬移的素材集合使用「尋找資料夾」。請檢查不確定的配對；系統不會只憑檔名確認素材。重新連結來源後，剪輯會保留。由瀏覽器管理的副本會隨專案移動；外部參照的素材可能需要重新連結。可移除磁碟機的實際行為仍需要平台驗證。

完整搬移流程見[媒體搬移與重新連結](media-portability.md)。若要把作品連同引用素材交付或換電腦，使用[Collect Media](collect-media.md)，並另外備份外部原始檔。

## 已知限制

- 本機服務以單一使用者工作站為範圍，不是多人協作或可直接公開的網路服務。
- 原始 360 素材、DNG、HDR 與部分編碼的預覽，取決於來源和本機工具支援。請以[來源支援](source-support.md)的具體條件為準。
- 可在超過最長片長時保留剪輯，但必須調整到限制內才能算繪。原始素材的可用長度和保護設定也會影響自動組合結果。
- 語音轉錄、本機模型與已支援的[語音生成](en/provider-generation.md)是選用功能；未設定時仍可進行基本剪輯。遠端服務可能另行計費。
- 自動化檢查無法取代你在實際電腦上的播放、聆聽與外部剪輯器驗證。
