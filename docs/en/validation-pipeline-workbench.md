## Automated Contracts & Architecture

| Area                                             | Evidence                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Information Architecture & Three Modes**       | Preserves `Library`, `Story`, `Edit`, `Export`, and `Versions` workspaces without displacing creative context. Provides three progressive modes: docked bottom status bar (`bar`), expandable drawer (`drawer` ~52vh over lower workspace), and full-viewport modal (`modal`). Switchable via top header toggle, Story toolbar action, and workbench control buttons.                                        |
| **Simplified 5 Stages**                          | Intuitive 5-stage workflow: 1. Materials (`materials`) -> 2. Story Plan (`storyPlan`) -> 3. Produce Clips (`produceClips`) -> 4. Preview & QA (`previewQa`) -> 5. Export (`export`). Fully mapped to the canonical 8 steps with collapsible advanced sub-steps and port dependencies.                                                                                                                        |
| **Card Standard ("Four Questions")**             | Every stage card explicitly answers: 1. What was used (`usedWhat`); 2. What was produced (`producedWhat`); 3. Current status (`currentStatus`); 4. Next action (`nextAction`).                                                                                                                                                                                                                               |
| **Media Playback Protections**                   | Photos render strictly as static thumbnails (`thumbnailUrl`). Audio features an inline mini audition player (`auditionPlay`/`auditionPause`) with elapsed time and duration tracking. Video preview features a static poster card with click-to-play; unselected cards never auto-play.                                                                                                                      |
| **Outdated Revision Transparency**               | Runs whose source drafts have changed externally are marked with an amber alert banner (`outdated`) and an immediate CTA to "Create New Run from Current Draft". Completed historical runs never pretend to be current outputs.                                                                                                                                                                              |
| **Non-Blocking Review & Indeterminate Progress** | Steps in `waiting-review` display clear action prompts without continuous infinite spinners. In-progress steps with dynamic durations use indeterminate progress bars rather than fabricating average completion percentages.                                                                                                                                                                                |
| **Error Diagnostics & Recovery**                 | Failed steps display the failing step name, concrete failure reason, and actionable recovery CTAs (e.g. import recording, retry).                                                                                                                                                                                                                                                                            |
| **Cross-View Navigation**                        | Provides bidirectional locator buttons: `[Locate in Story Graph]`, `[Locate in Storyboard]`, and `[Locate on Timeline]`. Returning to the workbench preserves previous selections, viewports, and scroll positions.                                                                                                                                                                                          |
| **Form & Polling Safety**                        | Background status polling (`getRun`) updates reactive run state without remounting editors, wiping dirty drafts, or resetting uncommitted input fields.                                                                                                                                                                                                                                                      |
| **Responsive Layout**                            | Responsive 3-pane workbench (stages nav, stage card, inspector) at 1440×900, collapsible 2-pane at 1280×720, and single-pane stacked drawer with stage outline at 1024×768.                                                                                                                                                                                                                                  |
| **Keyboard & IME Protection**                    | Keydown listeners explicitly check event targets; keystrokes inside `input`, `textarea`, or contenteditable elements are never swallowed by global hotkeys. Number keys `1`..`5` switch stages when outside form inputs; `Escape` collapses modal/drawer.                                                                                                                                                    |
| **Disclosures & Consent**                        | Prior to transmitting script text to external TTS services, displays data categories, target destination, estimated cost, and requires explicit user checkbox consent. Discloses that fine-grained partial cache reuse (Phase M11A) is not yet active.                                                                                                                                                       |
| **Real Services Acceptance**                     | Verified against real application services in `tests/integration/pipeline-workbench-acceptance.test.ts`: Journey 1 (missing narration audio supplemented with voice import), Journey 2 (review proposal, story origin verification, and adoption with legal receipt), Journey 3 (failure recovery via retryRun without mutating original snapshot), Journey 4 (external draft changes detected as outdated). |

## Native Conditions & Environment Notes

- **FFmpeg / FFprobe**: System PATH on this Windows development host does not include the `ffmpeg` executable. Test suites cleanly detect this and verify timeline durations, preview artifacts, and QA reports. Final physical bitstream encoding and decoding requires an environment with FFmpeg installed.
- **Python / Whisper Protocol**: Python 3 is not available in system PATH on this Windows host (`code 9009`). Pipeline workbench operates in pure TypeScript with zero Python or native binary dependencies.
