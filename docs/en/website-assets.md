# Website imagery and product evidence

The garden imagery on the public OpenFilm website is original generated artwork,
created on 2026-11-06 for this project. It depicts fictional garden architecture;
it is not a photograph of a named garden or evidence of a historical design rule.

| Asset                                                             | Origin                                                                                                        | Use                              |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| `garden-path.webp` and small variant                              | OpenAI image generation, original prompt describing one ordered route of angular stepping stones through moss | Homepage arrival                 |
| `garden-courtyard.webp` and small variant                         | OpenAI image generation, original prompt describing a quiet courtyard and three flat angular stone slabs      | Homepage closing and film poster |
| `product-library.webp`, `product-story.webp`, `product-edit.webp` | Actual OpenFilm browser workspace using generated garden media                                                | Product demonstration            |
| `garden-film.mp4`                                                 | Actual OpenFilm preview rendering from the same generated images                                              | Silent sample film               |

Garden image derivatives are distributed as project assets under Apache-2.0.
Navigation logos are small derivatives of the existing Desktop identity; the
originals remain in `apps/desktop/public/`.
Product identity and logo use remain subject to the repository's branding policy.
No third-party garden photographs, private media, GPS, personal projects, remote
fonts, analytics, or tracking scripts are included. Image generation is a design
asset creation step; visiting the site does not call a model or external service.

The product screenshots show an unreleased development workspace, not the scope
of the v0.4.0 source release. Source details and capture provenance are stored in
`images/origins.json`. The MP4 is a silent visual example, not audio-quality QA.

External references (JAANUS, Portland Japanese Garden, Dribbble and Awwwards)
could not be inspected because the execution network returned HTTP 403. Their
unread pages were not used as source imagery, quoted guidance, or proof of trends.

Native installers, camera hardware, GPU performance and real DaVinci Resolve
imports retain their separate workstation/manual verification requirements.
