# 開始使用

這份指南帶你從原始碼啟動 OpenFilm，建立第一個專案並輸出 MP4。基本流程在本機執行，不需要雲端帳號或 AI 供應商；選用遠端服務時，會另外要求設定與資料傳送同意。

最新穩定版是 **v0.4.0**。以下命令對應目前的 `main` 開發版本；使用發布版本時，請一併閱讀該版的 [release notes](https://github.com/bynanci/open-film/releases)。目前尚無可散布的原生桌面安裝程式。

## 1. 準備環境

先安裝 Git、**Node.js 24.14.0 或更新版本**、**pnpm 11.11.0**，以及可從終端機呼叫的 **FFmpeg 和 FFprobe**。確認版本：

```sh
node --version
pnpm --version
ffmpeg -version
ffprobe -version
```

下載程式碼和相依套件需要網路。一般剪輯不需要 Python 或模型；要使用選用的語音轉錄，再依[轉錄設定](en/transcription.md)安裝。

## 2. 啟動本機工作區

```sh
git clone https://github.com/bynanci/open-film.git
cd open-film
pnpm install --frozen-lockfile
pnpm dev
```

保持終端機開啟，在瀏覽器進入 [http://127.0.0.1:1420](http://127.0.0.1:1420)。你應該會看到 OpenFilm 歡迎畫面，終端機也會出現本機服務的 `server.ready` 訊息。

`pnpm dev` 同時啟動工作區（1420）與本機 API（4310）。完成工作並確認已儲存後，使用 Ctrl+C 停止開發程序。這些是本機開發服務，請勿直接公開到網際網路。

需要原生資料夾選擇器時，可安裝 Tauri 的平台先決條件後，先停止既有 `pnpm dev`，再執行：

```sh
pnpm --filter @openfilm/desktop tauri dev
```

此命令會啟動原生開發視窗及相同的本機服務。平台需求與封裝限制見[桌面指南](https://github.com/bynanci/open-film/blob/main/apps/desktop/README.zh-TW.md)。若要使用 CLI，可從儲存庫根目錄執行 `pnpm cli --help`。

## 3. 製作第一部影片

先選一小組可正常播放的照片與短片。歡迎畫面選擇**建立影片**，填入名稱、故事類型、影片語言和目標／最長片長；「進階」可設定專案位置。最大片長必須至少等於目標片長。

| 步驟     | 操作                                         | 應看到的結果                           |
| -------- | -------------------------------------------- | -------------------------------------- |
| 加入素材 | 在素材庫選擇檔案或資料夾，等待活動完成       | 縮圖與匯入結果出現在素材庫             |
| 整理     | 檢視素材、標記最愛並排除不需要的片段         | 保留要講述的時刻與可用素材             |
| 故事     | 建立故事、調整段落並指定重要素材，再建立剪輯 | 可編輯的剪輯出現在「剪輯」工作區       |
| 剪輯     | 調整順序與長度，等待「已儲存」後算繪預覽     | 能檢視目前影片；變更後舊預覽會標示過期 |
| 輸出     | 選擇「觀看／分享」輸出 MP4                   | 取得本機輸出位置和下載連結             |

完整操作、快捷鍵與復原方式請接著閱讀[製作流程](product-workflow.md)。完成後請實際播放 MP4，再重新開啟專案，確認剪輯與素材仍可讀取。

## 你的檔案存在哪裡？

專案存放在建立時選擇的資料夾，或設定中的預設位置。原生路徑匯入會參照原始素材；瀏覽器選檔或拖放則把副本存入本機專案。兩者都不會改寫原始檔，也不會因匯入而上傳雲端。

保留外部原始素材，並另外備份。搬動外接磁碟或專案前，先閱讀[媒體可攜與重新連結](media-portability.md)和[Collect Media](collect-media.md)。

## 常見起步問題

| 現象                            | 下一步                                                                                                   |
| ------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 無法開啟工作區                  | 查看啟動終端機；確認兩個服務都在執行，1420／4310 未被另一個 OpenFilm 程序占用                            |
| 找不到 FFmpeg／FFprobe          | 確認上述版本命令可執行，修正 PATH 後重新啟動服務                                                         |
| 某個素材無法預覽                | 先看[來源支援](source-support.md)；原始 360 素材可能需要在相機軟體中輸出平面影片                         |
| 素材顯示遺失                    | 接回磁碟或使用[重新連結](media-portability.md)，不要只憑檔名替換                                         |
| 轉錄或已支援的 TTS 供應商不可用 | 依[轉錄設定](en/transcription.md)或[TTS 設定](en/provider-generation.md)準備支援的功能；仍可繼續基本剪輯 |

仍有問題時，依[支援指南](https://github.com/bynanci/open-film/blob/main/SUPPORT.zh-TW.md)提供版本、平台、重現步驟與經過去識別處理的錯誤訊息。想改善 OpenFilm，請從[貢獻指南](https://github.com/bynanci/open-film/blob/main/CONTRIBUTING.zh-TW.md)開始。
