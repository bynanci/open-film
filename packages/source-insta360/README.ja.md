# Insta360 ソースアダプター

[繁體中文](README.zh-TW.md) · [English](README.md) · [日本語](README.ja.md)

`@openfilm/source-insta360` は既存のローカル `MediaSourceAdapter` ポートを実装し、`isInsta360Raw`、`inspectInsta360Raw`、`enrichInsta360Asset` を提供します。ソースファイルは変更しません。

- **レベル1：** Insta360／Arashi Vision のカメラまたはアプリのメタデータ、あるいは明示されたオリジナル参照に基づき、検査済みのフラット JPG／MP4 エクスポートを識別します。デコード済み寸法、時刻、GPS、コーデック、色、raw メタデータを保持します。ファイル名に「Insta360」があるだけでは識別根拠になりません。
- **レベル2：** `.insv`／`.insp` はカタログ項目として保持し、利用可能な場合は実際の ExifTool メタデータと制限付き FFprobe 情報を調べます。`.insv` は `360-video`、`.insp` は `image` です。どちらも `openfilm.preview.supported: false` とし、Insta360 Studio でスティッチ／リフレームしたフラット書き出しの読み込みを案内します。未対応または破損した内容もソース識別子と警告を保持し、raw フレームをフラットプレビューとして使いません。
- 明示的な EXIF 球面／正距円筒投影タグ、または FFprobe の Spherical Mapping side data がある場合もリフレーム済み書き出しが必要です。アスペクト比だけでは球面投影と判定しません。
- **レベル3：** スティッチング、手ブレ補正、リフレーム、実機の光学検証は未対応です。

`metadata["openfilm.insta360"]` はレベル、元の360ソース、リフレーム要否、根拠を記録します。関連付けには `explicit-metadata` または `named-sibling` の種別、URI、根拠、利用可能状態が含まれます。ファイル名による一致は関連の手がかりであり、同一コンテンツ、光学的な正しさ、製品対応を証明しません。シンボリックリンクは除外し、ソース走査はソート後の先頭10,000件に制限します。

アプリのインポートでは1回の処理中に `Insta360ImportContext` を共有し、各ディレクトリを一度だけ走査・ソートします。次回のインポートは新しい索引を作成するため、後から追加した raw ファイルも認識できます。テストはデコード可能な合成メディアと合成 raw 認識素材を使います。実機の Insta360 データと Studio 出力は手動で互換性を確認してください。
