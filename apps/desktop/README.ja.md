# OpenFilm デスクトップ版

[繁體中文](README.zh-TW.md) · [English](README.md) · [日本語](README.ja.md)

デスクトップワークスペースはローカルアプリケーションサービス（既定 `127.0.0.1:4310`）を使用します。素材のアップロードやリモートフォント、メディア、モデルの読み込みは行いません。リポジトリのルートで `pnpm dev` を実行して開発環境を起動します。フロントエンドは `pnpm --filter @openfilm/desktop build` でビルドできます。

## 作品の作成と言語

Welcome から作品の作成、プロジェクトを開く、最近使った作品の確認ができます。新規作成時にストーリー形式、作品の言語、目標／最大時間を設定します。UI は繁体字中国語、英語、日本語に対応し、切り替えてもエディターは再読み込みされません。UI 言語、作品の言語、ユーザーが入力した文章は独立しています。

## 編集と文字起こし

Edit ワークスペースには Story と Precision モードがあります。クリップのトリミング、写真の長さ、速度、音量、トランジション、画面位置を調整できます。波形やシーンカットの生成、マーカー追加、スナップ、分割にも対応します。Edit → Transcript では文章の修正、検索と置換、分割／結合、独立した取り消し履歴を利用できます。

変更は自動保存されます。保存競合やオフライン素材がある場合も、下書きを復元できる状態で保持します。再リンク時は照合根拠を表示し、評価、選択状態、編集効果を勝手に削除しません。元ファイルは変更されません。

## ネイティブアプリと書き出し

Tauri シェルは OS のファイル／フォルダー選択機能を提供します。必要なプラットフォーム依存関係を導入して、次を実行してください。

```sh
pnpm --filter @openfilm/desktop tauri dev
```

MP4 書き出しには互換性レポートが付きます。対応する場合は字幕や OpenTimelineIO などの受け渡し形式も出力できます。OTIO に保存された高度な効果は、移行先アプリで手作業による再設定が必要な場合があります。実際のインポート確認は別途必要です。

詳しい操作とプラットフォーム要件は[英語版デスクトップガイド](README.md)、[制作フロー](../../docs/product-workflow.md)、[文字起こし設定](../../docs/transcription.md)、[NLE 互換性](../../docs/nle-compatibility.md)を参照してください。
